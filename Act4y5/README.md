## Actividad N° 5 - Condicionales y Listas Dinámicas en Vue.js

### Descripción de la Actividad
Se desarrolló un componente interactivo de lista de tareas (`Tareas.vue`) aplicando directivas esenciales de Vue.js:
- **v-model:** Para capturar en tiempo real las tareas ingresadas en el campo de texto.
- **v-for:** Para recorrer el arreglo de tareas y mostrarlas dinámicamente en una lista (`<ul>`).
- **v-show:** Para alternar la visibilidad de la lista sin destruirla del DOM.
- **v-if:** Para mostrar un mensaje alternativo cuando la lista de tareas se encuentra vacía.

### Estructura agregada
- `src/components/Tareas.vue`: Componente para administrar el arreglo de tareas.
